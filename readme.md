## About Me:

Hello World! 👋
Saya adalah seorang developer dari Bandung, Indonesia. Perjalanan saya di dunia pemrograman cukup unik—awalnya saya belajar coding menggunakan IBM Assembly language... _just kidding_... saya mulai dari sebagai Excel VBA Developer, dan sejak saat itu terus tertarik untuk mengeksplorasi dan belajar bahasa pemrograman serta teknologi baru.

**What I typically work on:**

- Pengembangan aplikasi web dan _desktop cross-platform_ (menggunakan Electron.js).
- Membangun sistem _backend_ dan _frontend_ yang interaktif.
- Eksplorasi teknologi baru dari dasar hingga implementasi _deployment_.

## About Me:

Hello World! 👋
I'm a developer based in Bandung, Indonesia. My programming journey is a bit unique—I started coding using IBM Assembly language... _just kidding_... I actually started out as an Excel VBA Developer. Since then, I've been deeply interested in exploring and learning new programming languages and technologies.

**What I typically work on:**

- Developing web and cross-platform desktop applications (using Electron.js).
- Building interactive front-end and robust back-end systems.
- Exploring new technologies from the ground up to deployment implementation.
